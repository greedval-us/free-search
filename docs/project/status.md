# Статус и ограничения

Free Search находится в бета-версии. Контракты модулей, форматы ответов и интерфейс могут меняться между выпусками.

| Возможность | Что учитывать при эксплуатации |
| --- | --- |
| Telegram | Для поиска и сбора нужна авторизованная сессия MadelineProto. Telegram ограничивает частоту запросов. Поиску доступны только разрешённые публичные источники. |
| YouTube | Сбор зависит от квоты YouTube Data API и от доступности публичных видео и комментариев. |
| Bluesky и Mastodon | Настройте доступ к нужному сервису. Доступность удалённых публикаций и статистики в Mastodon зависит от федерации выбранного сервера. |
| Новости и медиа | Нужен доступный приложению и worker экземпляр SearXNG с JSON-выдачей. Движки влияют на полноту выборки, тональность и темы определяются эвристически. |
| Site Intel | DNS, WHOIS, HTTP и TLS отражают состояние сайта на момент проверки. Для исходящих запросов настройте сетевые ограничения и лимиты под своё окружение. |
| Подписки | Доступ активируется одноразовым кодом. Платёжный провайдер не подключён. |

## Фоновые задачи и хранение

Для Parser Runs приложению, обработчикам очереди и планировщику нужны общие приватное хранилище и кэш с атомарными блокировками. При исчерпании лимита частичный результат можно выгрузить. Размер сырого ответа API и внутренние повторы MadelineProto требуют отдельного контроля ресурсов. [Лимиты, блокировки и поддерживаемая топология](../architecture/parser-runs.md)

Перед развёртыванием проверьте каждый включённый источник с разрешённой учётной записью, восстановление прерванной задачи и доставку её результата. [Развёртывание](../deployment.md) · [Безопасность](../security.md)
